# API de Agendamento de Horários

Projeto desenvolvido com Java Spring Boot para gerenciamento de agendamentos.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- H2 Database
- Swagger/OpenAPI
- Maven
- Lombok
- Bean Validation

## Funcionalidades

- CRUD completo
- Busca por cliente
- Validação de dados
- Tratamento global de erros
- Impedir horários duplicados
- Documentação com Swagger
- DTOs para entrada e saída de dados
- Organização em camadas

## Como executar

- Clonar o projeto
- Abrir o projeto na IDE
- Executar a aplicação
- Acessar Swagger
